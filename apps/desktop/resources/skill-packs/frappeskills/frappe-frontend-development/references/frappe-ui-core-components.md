
# Frappe UI — Core Components

Adapted in part from frappe/frappe-ui (MIT): `skills/frappe-ui/COMPONENTS.md`, `spec/imperative-api.md`.

Verified catalog of the non-input frappe-ui (Vue 3) components: icons,
actions, display/feedback, navigation, and data display. Dialog, Toast,
Dropdown, ContextMenu, Popover, and HoverCard are in
[frappe-ui-overlays.md](frappe-ui-overlays.md). For project setup (install,
`main.js`, Tailwind, HTML scaffold, CSRF), see
[frappe-ui-setup.md](frappe-ui-setup.md). For every input control
(`TextInput`, `FormControl`, `Select`, `Combobox`, `MultiSelect`, `Checkbox`,
`Switch`, `DatePicker`, `Slider`, `Rating`, `FileUploader`, …), see
[frappe-ui-form-controls.md](frappe-ui-form-controls.md). See
[frappe-ui-components.md](frappe-ui-components.md) for the full file index.

frappe-ui is used by Frappe Cloud, Gameplan, Helpdesk, Frappe Insights, Frappe
Drive, and Frappe Builder. Under the hood: Vue 3, TailwindCSS, reka-ui
(headless primitives), TipTap (rich text, `frappe-ui/editor`), vue-sonner
(toasts), ECharts, dayjs, Lucide icons.

Every component below is verified against **frappe-ui `1.0.0-beta.29`**
(`src/components/**/*.api.md`, auto-generated by `scripts/propsgen.ts`, plus
`spec/*.md` for the components still mid-rewrite). Claims that differ from the
**`0.1.261`** baseline (`apps/crm/frontend/node_modules/frappe-ui`) are tagged
`(v1)`. Check `frontend/package.json` for the frappe-ui version actually
pinned in your app before relying on a `(v1)`-tagged API.

## Icons

Render any Lucide icon as a `<span>` with a `lucide-<kebab-case-name>` class —
never import a per-icon Vue component, never inline an `<svg>`
(`skills/frappe-ui/COMPONENTS.md`):

```vue
<span class="lucide-plus size-4 text-ink-gray-7" aria-hidden="true" />
```

Size with Tailwind's `size-*` utilities; color inherits `currentColor` (set
`text-ink-*` on the parent or the span). For any component prop typed
`icon: string | Component` (Button, Dropdown options, Dialog, Alert, Badge),
pass the same `"lucide-<name>"` string.

The `Icon` component (`src/components/Icon/Icon.vue`) wraps the same
convention as a component: `name: string | Component | null` accepts a
`lucide-*` string (renders via the Tailwind mask plugin), an emoji/symbol
string (rendered as text), a legacy Feather name (renders via the deprecated
`FeatherIcon`), or a Vue component (`<component :is>`). Falsy renders nothing.

## Actions

### Button

`src/components/Button/Button.vue`. Present with the same core surface in
`0.1.261`.

```vue
<Button variant="solid" theme="blue" @click="handleClick">Save</Button>
<Button variant="outline" theme="gray" size="sm">Cancel</Button>
<Button variant="subtle" icon-left="lucide-x">Close</Button>
<Button :loading="isLoading" loading-text="Saving...">Save</Button>
<Button icon="lucide-more-horizontal" />
<Button :route="{ name: 'Detail', params: { id: '001' } }">View</Button>
<Button link="https://example.com">External</Button>
```

Props: `theme` (`Theme`, default `'gray'`), `variant` (`Variant`, default
`'subtle'`), `type` (`'button' | 'submit' | 'reset'`, default `'button'`),
`label` (string), `loading` (boolean, default `false`), `size` (`Size`,
default `'sm'`), `icon` / `iconLeft` / `iconRight` (`string | Component`),
`tooltip` (string), `loadingText` (string), `disabled` (boolean, default
`false`), `route` (Vue Router destination), `link` (external URL string).
Slots: `prefix`, `icon`, `default` (overrides `label`), `suffix`. `route`
needs `app.use(router)`; see [frappe-ui-setup.md](frappe-ui-setup.md).

## Display

### Badge

`src/components/Badge/Badge.vue`. Props: `theme`
(`"blue"|"red"|"green"|"gray"|"amber"|"violet"|"orange"`, default `"gray"`),
`size` (`"md"|"sm"|"lg"`, default `"md"`), `variant`
(`"subtle"|"outline"|"solid"|"ghost"`, default `"subtle"`), `label`
(`string | number`). Slots: `prefix`, `default` (overrides `label`), `suffix`.
**(v1)** `0.1.261`'s `theme` union is narrower — `gray|blue|green|orange|red`
only, no `amber`/`violet`.

```vue
<Badge theme="green" variant="outline" label="Active" />
```

### Alert

`src/components/Alert/Alert.vue`. Props: `title` (string, **required**),
`theme` (`Theme`), `variant` (`"subtle"|"outline"`, default `"subtle"`),
`description` (string), `dismissible` (boolean, default `true`),
`modelValue` (boolean, default `true`, controls visibility). Slots: `icon`,
`description`, `footer`. Emits: `update:modelValue`, `dismiss`.

```vue
<Alert title="Error" theme="red" description="Failed to save changes.">
  <template #footer><Button size="sm" @click="retry">Retry</Button></template>
</Alert>
```

### Avatar

`src/components/Avatar/Avatar.vue`. Props: `image` (string URL), `label`
(string, fallback initials source), `size`
(`"md"|"xs"|"sm"|"lg"|"xl"|"2xl"|"3xl"`, default `"md"`), `shape`
(`"circle"|"square"`, default `"circle"`), `theme`
(`"gray"|"blue"|"green"|"amber"|"red"|"violet"`, default `"gray"`). Slots:
`default` (replaces initials/icon), `indicator` (bottom-right badge).

### Breadcrumbs

`src/components/Breadcrumbs/Breadcrumbs.vue`. Props: `items` (`BreadcrumbItem[]`,
required). Slots: `prefix`, `suffix` (each scoped `{ item }`).

### Divider

`src/components/Divider/Divider.vue`. Props: `orientation`
(`"vertical"|"horizontal"`, default `"horizontal"`), `position`
(`"start"|"center"|"end"`, default `"center"`), `flexItem` (boolean), `action`
(`DividerAction`). Prefer over a bare `<hr>`.

### Progress / Skeleton / Spinner / LoadingIndicator / LoadingText

`Progress` (`src/components/Progress/Progress.vue`): `value` (number,
required), `size` (`"md"|"sm"|"lg"|"xl"`, default `"sm"`), `label` (string),
`hint` (boolean, default `false`), `intervals` (boolean, default `false`),
`intervalCount` (number, default `6`). Slot `hint` overrides the percentage
readout.

`CircularProgressBar` (`src/components/CircularProgressBar/CircularProgressBar.vue`,
present in `0.1.261` too): `step` / `totalSteps` (numbers, required, defaults
`1`/`4`), `showPercentage` (boolean), `variant` (`"outline"|"solid"`, default
`"solid"`), `theme` (`"blue"|"red"|"green"|"orange"|"black"` or a custom
`{ primary, secondary }` object, default `"black"`), `size`
(`"md"|"xs"|"sm"|"lg"|"xl"`, default `"md"`), `themeComplete` (string, default
`"lightgreen"`).

`Skeleton` (`src/components/Skeleton/Skeleton.vue`) — **(v1)**, not in
`0.1.261`. No documented props beyond standard `class` sizing; a placeholder
block for loading states.

`Spinner` (`src/components/Spinner/Spinner.vue`): `size` (`SpinnerSize`,
`xs`=12px/`sm`=14px/`md`=16px/`lg`=20px; omit to size via classes, default
16px), `theme` (`SpinnerTheme`, omit to inherit text color), `track`
(boolean, default `false`, shows a faint background arc).

`LoadingIndicator` (`src/components/LoadingIndicator.vue`) is now a thin
wrapper around `Spinner`: prop `scale` (number, default `100`, percent).
`LoadingText` (`src/components/LoadingText.vue`): prop `text` (string,
default `'Loading...'`) — renders `LoadingIndicator` plus the text.

### Tooltip

`src/components/Tooltip/Tooltip.vue`. Props: `text` (string, default `""`,
ignored if a default slot child provides its own content), `hoverDelay`
(number seconds, default `0.5`), `placement`
(`"top"|"right"|"bottom"|"left"`, default `"top"`), `arrowClass` (default
`"fill-surface-gray-10"`), `disabled` (boolean, default `false`). Slots:
`default` (trigger), `body` (full custom tooltip body), `content` (custom
text inside the default body). Related: `TooltipBubble` (standalone bubble,
props `side`/`text`/`arrowClass`) and `TooltipProvider` (groups tooltips to
share one hover-delay window: props `hoverDelay`, `skipDelay` default `0.3`,
`disableHoverableContent`).

### KeyboardShortcut

`src/components/KeyboardShortcut.vue` renders a parsed key-combo string as
`<kbd>` badges (`bg` prop) or bare icon+letter spans, with Mac-aware
symbols (⌘/⇧/⌥). Composes with `useShortcut` (see Utilities) for the
`description`/label text.

## Navigation

### Tabs

`src/components/Tabs/Tabs.vue`. Props: `as` (string, container
element/component), `tabs` (`Tab[]`, required), `vertical` (boolean), `modelValue`
(`string | number`), `dir` (`'rtl'|'ltr'`, defaults to
`document.documentElement.dir`). Slots: `tab-item` (custom trigger render,
`{ tab }`), `tab-panel` (`{ tab }`). Emits: `update:modelValue`. Use for
full content tabs (top-level page sections).

### TabButtons

`src/components/TabButtons/TabButtons.vue`. Props: `options`
(`TabButton[]`; deprecated alias `buttons`), `modelValue` (`TabButtonValue`),
`type` (`TabButtonsType`, default `"subtle"`), `size` (`PillSize`, default
`"sm"`), `vertical` (boolean, default `false`), `direction`
(`TabButtonsDirection`, default `"left"`, used only with `type='browser-tab'`
+ `vertical`). Slots: `prefix`/`suffix` (`{ button }`). Emits:
`update:modelValue`. Use for inline segmented controls (filter/view
switches), not full-page navigation.

## Data display

### Tree

`src/components/Tree/Tree.vue`. Props: `nodes` (`TreeNode[]`, required,
forest roots with nested `children`), `nodeKey` (string, default `"key"`),
`draggable` (boolean, default `false` — drag onto a node to reparent, between
siblings to reorder), `move` (`(ctx: MoveContext) => boolean`, gates a drop
after the built-in self/descendant guards), `guides`
(`"connectors"|"lines"|"none"`, default `"connectors"`), `disabled` (boolean,
default `false`), `expanded` (boolean, default `false`, two-way
expand/collapse-all switch; per-node state lives on `node.expanded`). Slots:
`item`, `item-prefix`, `item-label`, `item-suffix`, `empty`. Emits:
`update:expanded`, `drag-start` (`TreeNode`), `drag-end` (`DropInfo | null`).

### Calendar

`src/components/Calendar/Calendar.vue`. Month/week/day calendar view; per
`spec/imperative-api.md` it is mid-rebuild into composition-based components
under a future `frappe-ui/calendar` subpath, so treat its API as less stable
than the rest of this catalog. Key props (`CalendarPublicProps`): `events`
(`CalendarEvent[]`, required — `id`/`name`, `title`, `date` or
`fromDate`/`toDate`, `fromTime`/`toTime`, `color`, `isFullDay`, …), `config`
(`Partial<CalendarConfig>` — `scrollToHour`, `disableModes: CalendarMode[]`,
`defaultMode: 'Day'|'Week'|'Month'`, `isEditMode`, `eventIcons`,
`hourHeight`, `enableShortcuts`, `showIcon`, `timeFormat: '12h'|'24h'`,
`weekends`, `noBorder`), `onClick`/`onDblClick`/`onCellClick` callback props.

### Charts

`src/components/Charts/`. Each chart wraps `ECharts` (`echarts`, SVG
renderer) with a typed `config` prop; also present in `0.1.261`.

- `AxisChart` — `config: AxisChartConfig`: `data`, `title`, `subtitle?`,
  `colors?`, `dir?`, `xAxis: { key, type: 'category'|'time'|'value',
  timeGrain?, title?, echartOptions? }`, `yAxis`/`y2Axis?: { title?, yMin?,
  yMax?, echartOptions? }`, `swapXY?`, `stacked?`, `series:
  (BarSeriesConfig|LineSeriesConfig|AreaSeriesConfig)[]`, `echartOptions?`.
  Series share `{ name, type, color?, axis?: 'y'|'y2', showDataLabels?,
  echartOptions? }`; bar adds `stackName?`; line adds `lineType?`,
  `lineWidth?`, `showDataPoints?`; area adds `showDataPoints?`,
  `fillOpacity?`. Options are built by `useAxisChartOptions(config)`
  (also exported standalone).
- `DonutChart` — `config: DonutChartConfig`: `data`, `title`, `subtitle?`,
  `colors?`, `dir?`, `categoryColumn`, `valueColumn`, `maxSliceCount?`,
  `showInlineLabels?`, `echartOptions?`.
- `FunnelChart` — `config: FunnelChartConfig`: `data`, `title`, `subtitle?`,
  `colors?`, `dir?`, `categoryColumn`, `valueColumn`, `showPercentages?`,
  `echartOptions?`.
- `NumberChart` — `config: NumberChartConfig`: `title`, `value`, `prefix?`,
  `suffix?`, `delta?`, `deltaPrefix?`, `deltaSuffix?`, `negativeIsBetter?`.
  Slots: `body`, `title`, `subtitle`, `delta` (all scoped with a
  `formatValue` helper).
- `ECharts` — the shared primitive: `options: EChartsOption`, `events?:
  { click }`, `error?: string`, `class?: string`. Auto-resizes via a
  debounced `ResizeObserver`.

```vue
<AxisChart :config="{
  title: 'Revenue', data: rows,
  xAxis: { key: 'month', type: 'category' },
  yAxis: {},
  series: [{ name: 'Revenue', type: 'bar' }],
}" />
```

### GridLayout

`GridLayout` (`src/components/VueGridLayout/Layout.vue`, exported as
`GridLayout`; present in `0.1.261` too) wraps `grid-layout-plus`. Props:
`cols` (number, default `12`), `rowHeight` (number, default `52`), `disabled`
(boolean, disables drag/resize). `v-model` (`Layout` = `LayoutItem[]`, each
`{ i, x, y, w, h, minW?, minH?, maxW?, maxH?, static?, isDraggable?,
isResizable? }`).

## Directives

Registered manually per app — `FrappeUI` (the `app.use(FrappeUI)` plugin)
does **not** auto-install them:

```ts
import { focusDirective, onOutsideClickDirective, visibilityDirective } from 'frappe-ui'
app.directive('focus', focusDirective)
app.directive('on-outside-click', onOutsideClickDirective)
app.directive('visibility', visibilityDirective)
```

- `focus` (`src/directives/focus.ts`) — on mount, focuses the first
  focusable descendant of the bound element (or the element itself if it is
  focusable); `binding.value === false` skips it; `v-focus:autoselect` also
  selects text in a focused `<input>`/`<textarea>`.
- `on-outside-click` (`src/directives/onOutsideClick.ts`) — calls
  `binding.value(event)` on any document click outside the bound element.
- `visibility` (`src/directives/visibility.ts`) — wraps an
  `IntersectionObserver`; calls `binding.value(visible, entry)` whenever
  intersection changes.

## Utilities

- `dayjs`, `dayjsLocal(dateTimeString?)` (`src/utils/dayjs.ts`) — `dayjs` is
  the configured dayjs instance (`relativeTime`, `localizedFormat`, `isToday`,
  `duration`, `utc`, `timezone`, `advancedFormat`, `customParseFormat`
  plugins pre-loaded). `dayjsLocal` converts a datetime from the app's
  `systemTimezone` config to the browser's (or configured `localTimezone`);
  falls back to plain `dayjs()` if no `systemTimezone` is set via
  `setConfig`.
- `debounce(func, wait, immediate?)` (`src/utils/debounce.ts`) — returns a
  debounced function with a `.cancel()` method; call it on unmount to drop a
  pending trailing call.
- `fileToBase64(file: File): Promise<string>` (`src/utils/file-to-base64.ts`).
- `fileSize` (`src/utils/fileSize.ts`) — `getMaxFileSize()` reads the
  `maxFileSize` app config; `formatBytes(bytes)`; `fileSizeLimitMessage(file)`
  returns a human-readable over-limit message or `null`.
- `useTheme()` (`src/utils/theme.ts`) — singleton light/dark/system theme
  state shared across every consumer: `{ currentTheme, toggleTheme,
  setTheme(theme), initializeTheme, getSystemTheme }`. Applies
  `<html data-theme>` and persists to `localStorage`.
- `useScreenSize()` / `useIsMobile(breakpoint = 640)`
  (`src/composables/useScreenSize.ts`) — reactive `{ width, height }`
  updated on resize; `useIsMobile` is a derived `ComputedRef<boolean>`.
- `useShortcut(shortcuts: ShortcutConfig | ShortcutConfig[])`
  (`src/composables/useShortcut.ts`) — registers global keyboard shortcuts,
  auto-cleaned up on unmount. `ShortcutConfig`: `key` (required), `ctrl?`,
  `shift?`, `alt?`, `description` (required, shown in the shortcuts modal),
  `group?`, `triggeredOn?: 'press'|'hold'` (default `'press'`), `handler?`,
  `onHold?`/`onRelease?` (for `'hold'`), `preventDefault?` (default `true`),
  `allowInInput?` (default `false`), `allowInDialog?` (default `false`),
  `condition?: () => boolean`. Also exports `formatShortcutLabel(config)`
  (e.g. `"⌘ K"` / `"Ctrl + K"`) and `getActiveShortcuts()`.
- `KeyboardShortcut` / `KeyboardShortcutsModal` — see Display above; the
  modal (`src/components/KeyboardShortcutsModal/`) lists shortcuts
  registered via `useShortcut`, grouped by `group`.
- `CommandPalette` / `CommandPaletteItem`
  (`src/components/CommandPalette/CommandPalette.vue`) — Cmd-K style palette.
  Props: `show` (boolean, `v-model:show`), `searchQuery` (string,
  `v-model:searchQuery`), `groups` (array). Emits `select`. Not built on
  `Dialog` internally; compose it inside `<Dialog bare>` for the modal shell
  (`skills/frappe-ui/COMPONENTS.md`).

## Deprecated top-level exports

Marked `@deprecated` in `src/index.ts`; all still exported in
`1.0.0-beta.29` but scheduled for removal at `1.0.0` per
`v1-release/deprecated-removals.md` (ADR-0008) — do not use in new code.

| Deprecated export | Replacement |
|---|---|
| `Autocomplete` | `Combobox` (single value) or `MultiSelect` (multiple) |
| `Card` | Layout markup, or a domain-specific component (`bg-surface-base rounded border border-outline-gray-1 p-4`) |
| `ConfirmDialog` (SFC) | `dialog.confirm(...)` |
| `confirmDialog` (function) | `dialog.confirm(...)` |
| `FeatherIcon` | `lucide-*` icon string, or the `Icon` component |
| `Input` | `TextInput` or `FormControl` |
| `ListItem` | List primitives from `frappe-ui/list`, or app-owned row markup |
| `MonthPicker` | `Select` |
| `Toast` (the SFC) | The imperative `toast(...)` API |
| `ThemeSwitcher` | `Select` plus the `useTheme` composable |
| `TextEditor` (+ root exports) | The `frappe-ui/editor` subpath |
| `TextEditor/extensions/{image,suggestion}` | Extensions from `frappe-ui/editor` |
| `FormControl type="autocomplete"` | `Combobox` |
